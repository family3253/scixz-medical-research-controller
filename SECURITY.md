# Security and privacy boundary

SciXZ can process manuscripts, research data, and browser-assisted evidence. Treat all input files and external pages as untrusted content.

- Do not commit API keys, access tokens, cookies, browser profiles, PHI, patient-level data, unpublished manuscripts, reviewer files, or private journal profiles.
- Do not send full manuscripts or restricted data to JANE, iPubMed, or other external services without explicit authorization and a privacy review.
- Keep machine-specific binding files and run manifests outside the public repository.
- Report suspected credential or privacy exposure privately to the repository owner; do not open a public issue containing the secret.
