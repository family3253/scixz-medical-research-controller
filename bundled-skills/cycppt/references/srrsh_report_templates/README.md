## 强制规则

- 邵逸夫医院汇报任务必须先确认院区，再选择封面。
- 不设置默认院区；请求中未明确院区时必须询问用户。
- 封面必须同时匹配院区名称和对应院区建筑照片，不能只修改文字。
- 封面只替换议题、日期、姓名等业务字段，不改变医院标识、合作机构标识、红色底栏和整体构图。
- 结尾页为五个院区通用的 `THANK YOU / 谢谢！` 页面。
- 普通医学汇报或其他医院任务不得自动使用本模板。

使用 `scripts/resolve-srrsh-report-template.py` 查询资源或向 `ppt_plan.json` 注入首尾页模板绑定。

注入的绑定会锁定 `style_prompt.json`，因此首尾页优先遵守医院官方红白模板，不会被整套 PPT 选择的其他医学风格覆盖。
