# Academic Chart to New Media

## Purpose

Convert rigorous academic findings into visually clearer, lighter-weight public communication graphics without distorting the underlying science.

This is not about making the figure flashy for its own sake. It is about changing the communication layer for a different audience.

## When to Use

Use this skill whenever the user:
- wants to convert a paper chart into social-media, video, or outreach visuals
- asks for ECharts, Plotly, or lightweight web-friendly figure configs
- wants to simplify a dense manuscript figure for public communication
- needs a script or visual brief for a science explainer, tweet thread, Bilibili/视频号/公众号 graphic, or presentation recap
- wants to retain scientific integrity while removing over-technical clutter

## Core Rule

Simplify presentation, not evidence.

That means:
- remove nonessential academic clutter when appropriate
- preserve the direction, magnitude, and interpretation of the main findings
- never exaggerate certainty
- never imply causality beyond the original result

## Default Deliverables

Depending on the user's request, provide one or more of:
- a simplified visualization concept
- chart annotation copy for the public audience
- ECharts or Plotly starter config
- a “what to keep / what to remove” transformation guide
- headline + subtitle + callout wording for the figure

If unspecified, provide:
1. the key takeaway in one sentence
2. a simplified chart design brief
3. starter ECharts or Plotly config

## Simplification Strategy

When adapting an academic figure, decide what to keep:

### Usually keep
- the main comparison or trend
- units and scale clarity
- essential uncertainty caveat when it changes interpretation
- one or two critical annotations

### Often reduce or remove
- overly dense legends
- minor subgroup detail that distracts from the headline
- full model notation
- dense confidence interval clutter if the audience goal is broad explanation and the exact interval is not the message
- manuscript-style panel overload

## Audience Lens

Tune the output to public attention patterns:
- one main message per visual
- short labels
- strong but tasteful contrast
- clear focal annotation
- immediate takeaway within 2-3 seconds of viewing

## Workflow

1. Identify the paper's real takeaway.
2. Strip away nonessential academic packaging.
3. Decide the best public-facing chart form.
4. Write concise annotation language.
5. Produce config/code or a transformation brief.
6. Add one short note about scientific caveats if needed.

## Chart-Type Heuristics

- dense multi-series academic line chart -> simplified highlight line chart
- detailed coefficient plot -> ranked effect bar / dot plot
- manuscript heatmap -> cleaned, annotated spotlight heatmap
- complex grouped bars -> one-key-comparison bar chart with callout
- multi-panel supplemental result -> carousel or sequence of two simpler views

## Output Structure

Prefer this structure:
- **核心信息**
- **可视化改造思路**
- **建议删减项**
- **ECharts / Plotly 配置草稿**
- **科学性提醒**

## What to Avoid

Avoid:
- sensational color and motion that changes perceived importance
- removing all uncertainty when uncertainty is central to the conclusion
- overstating a marginal or null result as a dramatic story
- copying manuscript visuals 1:1 when the whole point is audience adaptation

## Response Style

Be bilingual in spirit: scientifically honest, but audience-aware. The result should feel like a strong science communicator worked with a careful methodologist.
