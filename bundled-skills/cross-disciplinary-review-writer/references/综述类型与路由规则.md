# 综述类型与路由规则

## 目标
在进入正式检索前，先判定“应该写哪一类综述”，再选择合适的证据强度、闸门口径和写作结构。

## 必须输出
- 主综述类型
- 选择理由
- 是否允许输出强结论
- 适用闸门档位
- 是否需要质量评价/偏倚评价
- 预期交付物

## 常用综述类型

### 1. 投稿级叙述/综合综述
适用情形：
- 目标是期刊综述、学位综述章节或基金前期综述
- 主题可以稳定拆成 3–6 个子主题
- 需要综合不同研究路线、证据和争议

输出重点：
- 主题化综合
- 横向比较
- 代表性证据与争议分析

默认闸门：
- 使用投稿级默认档位

### 2. 范围综述 / 证据地图
适用情形：
- 主题边界尚不稳定
- 研究类型分散，先要做全景摸底
- 目标是回答“有哪些研究、覆盖到哪里、空白在哪里”

输出重点：
- 研究分布
- 主题/方法/场景覆盖图
- 明确证据空白

限制：
- 不宜把范围综述写成强因果定论
- 对强结论的证据要求应单独加严

### 3. 系统化证据综述
适用情形：
- 研究问题明确
- 纳排标准可以清楚定义
- 需要较高的方法透明度与可复核性

输出重点：
- 检索与筛选过程可复现
- 质量评价/偏倚评价
- 结论与证据强度严格对应

额外要求：
- 不能只靠固定数量门槛判断完成度
- 必须强调“是否已纳入全部符合条件的研究”或给出明确边界

### 4. 综述的综述 / umbrella review
适用情形：
- 主题已有较多系统综述或 meta-analysis
- 目标是综合已有二级证据

输出重点：
- 综述层级证据比较
- 不同综述结论冲突的来源
- 综述本身的方法质量

额外要求：
- 优先纳入高质量系统综述和 meta-analysis
- 必须评价综述层面的质量

### 5. 理论 / 批判 / 经典文献综述
适用情形：
- 主题以概念、理论、历史脉络或经典文本为核心
- 目标是提出概念整合、理论比较或批判性重构

输出重点：
- 概念边界
- 理论流派
- 经典文献与新近文献的对话

限制：
- 不能机械套用经验研究密度要求
- 不能因为文献数量较少就忽略经典文本覆盖

## 路由判断问题
优先回答以下问题：

1. 本任务要回答的是“有什么研究”“证据是否支持某个结论”还是“如何整合理论”？
2. 主题能否定义明确的纳排标准？
3. 是否需要形成强结论或可直接支撑政策/实践建议？
4. 核心证据是一手研究、二手综述，还是经典理论文本？
5. 目标期刊或输出场景更偏 narrative、scoping、systematic 还是 critical review？

## 选择规则
- 若目标是综合领域主线并形成投稿级正文，优先“投稿级叙述/综合综述”。
- 若领域尚散、先要摸清边界，优先“范围综述 / 证据地图”。
- 若研究问题明确且需要高可复核性，优先“系统化证据综述”。
- 若核心材料是已有综述而不是原始研究，优先 “umbrella review”。
- 若主题以概念、理论或经典文本为主，优先“理论 / 批判 / 经典文献综述”。

## 交叉主题处理
- 可以同时声明主类型 + 辅类型，但必须只有一个主类型。
- 主类型决定闸门口径和正文结构。
- 辅类型只用于补充某一阶段的工作重点，不得混淆最终输出标准。
