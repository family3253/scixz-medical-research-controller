# 跨学科投稿级综述写作器

按“主题规格化 → 学科分流 → 投稿级可行性预判 → 数量与覆盖闸门 → 检索策略 → 候选池 → 合法全文获取 → 双层筛选与全文评阅 → 证据提取与分级 → 写作框架与图表规划 → 论点映射与提纲 → 初稿写作 → 二轮重构与终检”的顺序工作。

## 运行环境与资源约束
- `scripts/` 下同时提供 Python 和 PowerShell 实现。Python 版本默认使用标准库，无额外第三方依赖；Windows 环境可直接优先使用 `.ps1`。
- 若当前环境没有 Python，仍可使用 PowerShell 版本完成初始化、导入去重和闸门检查。
- 调整任意 CSV 模板前，先检查[项目 CSV 字段规范](references/项目CSV字段规范.md)并同步更新 `scripts/review_project_schema.py` 和 `scripts/review_project_schema.psd1`。
- 需要参考成品目录和表格填法时，优先查看[最小示例项目](assets/example-project/minimal-review-project)。

## 快速上手
推荐在 Windows 上按以下最短链路启动：

1. 安装 skill 到个人目录。
2. 初始化一个新的综述项目目录。
3. 导入并去重外部题录 CSV。
4. 运行项目校验脚本，确认模板与字段完整。
5. 生成闸门检查报告，判断当前是否达到目标档位。
6. 如果已有明确主题，优先直接使用一键脚本生成真实项目骨架。

Windows 常用调用示例：
- `powershell -ExecutionPolicy Bypass -File scripts/安装技能.ps1`
- `powershell -ExecutionPolicy Bypass -File scripts/一键初始化综述项目.ps1 <输出目录> -Topic <真实主题>`
- `powershell -ExecutionPolicy Bypass -File scripts/初始化综述项目.ps1 <输出目录>`
- `powershell -ExecutionPolicy Bypass -File scripts/导入并去重候选文献.ps1 <输入CSV...> -Output <候选文献表.csv>`
- `powershell -ExecutionPolicy Bypass -File scripts/校验综述项目.ps1 <项目目录>`
- `powershell -ExecutionPolicy Bypass -File scripts/生成闸门检查报告.ps1 <项目目录> -GateProfile A`

## 任务前置一：先判定模式
先把当前任务归入以下 4 种模式之一：

1. **完整投稿级综述模式**：从零开始，完整跑完整条流程。
2. **投稿级证据梳理模式**：做到候选池、全文评阅、证据提取、论点映射，不直接写正文。
3. **已有文献的投稿级写作模式**：用户已有较完整文献池，重点做框架、提纲、正文与终检。
4. **已有草稿的投稿级增强模式**：用户已有综述初稿，重点做证据核查、结构重构、批判性增强和投稿终检。

若用户没有明确说明模式，默认按“完整投稿级综述模式”工作。

## 任务前置二：再判定综述类型与闸门档位
先使用[综述类型与路由规则](references/综述类型与路由规则.md)判定本任务属于哪一类综述，再决定门槛口径和输出强度。

至少明确：

- 主综述类型
- 选择理由
- 是否允许强结论
- 适用的闸门档位
- 是否需要质量评价/偏倚评价

如果用户未指定综述类型，必须根据任务目标在“投稿级叙述/综合综述、范围综述/证据地图、系统化证据综述、综述的综述/umbrella review、理论/批判/经典文献综述”中选择最合适的一类；必要时允许主类型 + 辅类型，但必须说明以哪一种为主。

## 第一步：生成任务单
先生成一张任务单，至少包含：

- 当前模式
- 主综述类型
- 闸门档位与选择理由
- 研究主题
- 拟投稿用途或写作用途
- 输出语言
- 学科类别
- 目标期刊、学位论文、基金申请或未指定
- 用户当前已有材料（题目、摘要、文献列表、PDF、草稿）
- 是否按投稿级标准执行（默认是）
- 是否需要质量评价/偏倚评价
- 预期输出级别（投稿级完成稿、证据梳理、初步框架、局部专题述评）

如果主题仍然过宽、过窄或表达模糊，先进入[主题规格化规则](references/主题规格化规则.md)。

## 第二步：完成主题规格化
没有完成主题规格化，不进入检索。

主题规格化必须输出：

- 标准化中文题目
- 英文工作题目
- 研究对象
- 核心问题
- 时间边界
- 中英文关键词与同义词组
- 一级子主题建议
- 应排除的相邻方向

参考：[主题规格化规则](references/主题规格化规则.md) 和 [选题说明模板](assets/模板资源/选题说明模板.md)。

## 第三步：学科分流
根据主题将任务归入以下学科路线，并加载对应规则文件：

- 医学与生命科学 → [医学与生命科学规则](references/医学与生命科学规则.md)
- 计算机与人工智能 → [计算机与人工智能规则](references/计算机与人工智能规则.md)
- 工程技术 → [工程技术规则](references/工程技术规则.md)
- 材料化学 → [材料化学规则](references/材料化学规则.md)
- 社会科学 → [社会科学规则](references/社会科学规则.md)
- 教育与人文 → [教育与人文规则](references/教育与人文规则.md)

如果是明显交叉主题，允许主路线 + 辅路线并行，但写作时必须说明交叉边界。

## 第四步：投稿级可行性预判
在大规模检索前先判断主题是否适合投稿级综述：

- 是否存在足够数量的学术文献
- 是否能够拆分成 3 个以上有证据支撑的一级子主题
- 是否存在稳定的研究主线、方法路线或争议点
- 是否有足够近年的研究覆盖前沿

若明显不适合投稿级综述，应先建议缩小或扩展范围，再继续。

## 第五步：设定投稿级数量与覆盖闸门
默认加载[投稿级文献数量门槛规则](references/投稿级文献数量门槛规则.md)。

默认投稿级门槛只适用于“经验研究占主导的投稿级叙述/综合综述”。若任务属于范围综述、系统化证据综述、umbrella review、理论/批判/经典文献综述或小众交叉主题，必须先按规则文件调整门槛档位并写明理由。

默认档位门槛：

- 候选文献总量不少于 150 篇
- 去重后进入初筛不少于 120 篇
- 初筛后保留不少于 80 篇
- 完成全文评阅不少于 50 篇
- 核心精读不少于 35 篇
- 深度证据提取不少于 30 篇
- 可直接支撑正文主论点的核心证据不少于 20 篇

同时检查：

- 每个一级子主题的文献覆盖是否达线
- 近五年与近三年文献占比是否达线
- 原始研究、综述、指南/标准/政策文本比例是否合理
- 是否覆盖主要研究路线、争议点和代表性成果
- 当前闸门口径是否与综述类型匹配

任何一项未达线，都不能输出“投稿级完成稿”。必要时降级为“高质量研究脉络梳理”或“投稿级证据梳理”。

## 第六步：设计检索策略
使用[检索策略模板](assets/模板资源/检索策略模板.md)，生成：

- 中文关键词组
- 英文关键词组
- 同义词扩展
- 概念组拆分
- 布尔检索式
- 数据库适配表达
- 时间窗口
- 文献类型优先级
- 检索日期、检索批次与版本号
- 纳入/排除标准摘要

不能只给若干关键词，必须给出可复现的检索逻辑。

## 第七步：建立候选文献池
先构建候选池，再决定获取全文。使用[候选文献表模板](assets/模板资源/候选文献表模板.csv)。

若起点是 Europe PMC、PubMed 或通用数据库导出的 CSV，可先运行[导入并去重候选文献脚本](scripts/导入并去重候选文献.py)生成候选文献表 schema，再进入人工筛选。
Windows 环境可直接使用同名 PowerShell 版本：`scripts/导入并去重候选文献.ps1`。

这一阶段应完成：

- 汇总题录
- 去重
- 年份与来源标注
- 数据库与检索批次标注
- 文献类型标注
- 子主题归属标注
- 标题/摘要级相关度判断
- 去重状态记录
- 检查是否达到候选数量门槛

如果候选池数量不足，自动进入扩检：

- 扩展同义词
- 扩展相关概念
- 调整时间窗口
- 增补数据库
- 检查主题是否过窄

## 第八步：合法全文获取与下载
优先对初筛保留和疑似核心文献尝试合法全文获取。严格按[合法全文获取与下载规则](references/合法全文获取与下载规则.md)工作。

优先顺序：

1. 开放获取正式版本
2. 出版社合法可获取版本
3. 机构知识库版本
4. 作者公开存档版本
5. 合规预印本版本

必须记录：

- 获取状态
- 来源
- 版本
- PDF 状态
- 文件名
- 获取日期
- 许可/版权说明
- 是否可读
- 是否为核心全文
- 是否仅有摘要
- 是否付费受限

使用模板：

- [全文获取登记表模板](assets/模板资源/全文获取登记表模板.csv)
- [全文评阅登记表模板](assets/模板资源/全文评阅登记表模板.csv)

## 第九步：双层筛选与全文评阅
筛选分两层，不可混用：

### 第一层：摘要筛选
使用[摘要筛选记录表模板](assets/模板资源/摘要筛选记录表模板.csv)判断是否进入全文阶段。

### 第二层：全文筛选
使用[全文筛选记录表模板](assets/模板资源/全文筛选记录表模板.csv)判断是否真正能支撑综述正文。

两层筛选都必须记录：

- 命中的纳入标准
- 命中的排除标准
- 决策依据
- 筛选日期与筛选人

同时把文献分成：

- A 类：核心证据
- B 类：重要辅助
- C 类：背景支持
- D 类：排除

若某一一级子主题全文证据明显不足，不得把它写成独立重点章节。

## 第十步：证据提取、证据分级与矛盾点整理
先读[证据提取字段规则](references/证据提取字段规则.md)，再使用[证据提取表模板](assets/模板资源/证据提取表模板.csv)和[阅读笔记模板](assets/模板资源/阅读笔记模板.md)。

必须区分三件事：

1. **证据提取**：研究问题、对象、方法/框架、数据/材料、主要发现、优点、局限。
2. **证据分级**：哪些能支撑主论点，哪些只是辅助或背景。
3. **矛盾点整理**：结论不一致、方法差异、数据差异、评价指标差异及其可能原因。

不得只复述摘要；必须标明该文献在综述中的作用、拟放章节、质量评价/偏倚风险和与其他研究的关键冲突。

## 第十一步：判定写作框架并规划图表
先读[综述写作框架规则](references/综述写作框架规则.md)，再使用[写作框架模板](assets/模板资源/写作框架模板.md)和[图表规划模板](assets/模板资源/图表规划模板.md)。

如果项目目录中的候选池、筛选、评阅和证据表已有基础内容，可先运行[生成统计图表草案脚本](scripts/生成统计图表草案.ps1)自动生成 Markdown + Mermaid 草案，再回填到图表规划模板。

先在以下框架中选择最合适的一种或两种组合：

- 时间演进型
- 主题模块型
- 方法路线型
- 应用场景型
- 理论流派型
- 争议问题型
- 问题—解决方案型
- 机制—证据—局限型

然后规划：

- 概念图
- 方法比较表
- 代表性研究对比表
- 证据矩阵表
- 发展脉络图

没有完成框架判定，不进入正式提纲。框架选择必须与综述类型一致，例如范围综述不得伪装成强因果叙述，理论/批判综述不得套用纯经验研究结构。

## 第十二步：论点映射、提纲生成与初稿写作
先用[论点映射模板](assets/模板资源/论点映射模板.md)建立“论点—证据”关系，再用[综述提纲模板](assets/模板资源/综述提纲模板.md)形成章节层级，最后再用[初稿模板](assets/模板资源/初稿模板.md)写正文。

顺序必须是：

1. 论点映射
2. 综述提纲
3. 初稿写作

正文要求：

- 以主题归纳与横向比较为主
- 交代主要研究路线、代表性证据和争议点
- 明确研究局限与未解决问题
- 不写成按作者逐篇罗列的流水账
- 未来方向必须建立在当前证据缺口上
- 关键段落应能回溯到“论点—证据—章节”映射

## 第十三步：二轮重构、反向核查与投稿终检
使用[二轮修改清单模板](assets/模板资源/二轮修改清单模板.md)和[最终核查模板](assets/模板资源/最终核查模板.md)。

如果任务已经在初始化后的项目目录中推进，可使用[生成闸门检查报告脚本](scripts/生成闸门检查报告.py)汇总当前候选池、筛选、评阅、证据提取和闸门达线情况。
Windows 环境可直接使用同名 PowerShell 版本：`scripts/生成闸门检查报告.ps1`。

必须完成三件事：

1. **二轮重构**：删除流水账表达，增强比较与批判分析，平衡章节轻重。
2. **反向核查**：从正文倒查证据，看每个强结论是否真的有足够支撑。
3. **投稿终检**：检查标题、摘要、正文、图表、证据覆盖、代表性路线遗漏、无证据判断、检索与筛选记录完整性等问题。

未通过终检，不标记为投稿级完成稿。

## 全流程硬规则

1. 没有完成主题规格化，不进入检索。
2. 没有完成综述类型判定与闸门档位记录，不进入检索。
3. 没有通过对应档位的数量与覆盖闸门，不进入投稿级成稿。
4. 没有合法获取的全文证据，不把对应研究写成强结论。
5. 没有完成写作框架判定，不进入正式提纲。
6. 每个一级章节至少有 3 篇核心证据，除非综述类型允许更低门槛且已书面说明。
7. 每个关键论点至少有 2 个独立来源。
8. 每个强结论至少有 3 个来源支撑。
9. 单篇研究不得写成领域共识。
10. 必须显式处理证据矛盾与局限，不能只写共识。
11. 检索、筛选、获取和评阅过程必须保留可追溯记录。
12. 系统化证据综述和 umbrella review 必须显式做质量评价或偏倚评价。
13. 不得虚构文献、DOI、期刊、研究方法、实验结果或参考文献条目。
14. 若数量或质量未达当前综述类型门槛，应明确降级输出，不得伪装成投稿级综述。
