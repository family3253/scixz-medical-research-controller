# Logic Skeleton Rewriter

## Purpose

Repair academic text at the level of reasoning structure, not just vocabulary polish.

## When to Use

Use this skill whenever the user:
- says the paragraph feels fragmented, jumpy, repetitive, or logically weak
- wants transitions and argument flow improved
- needs help rebuilding a premise -> inference -> conclusion chain
- wants diagnosis of structural problems before rewriting
- prefers keeping the original terminology while fixing the skeleton underneath

## Core Rule

Prioritize argument structure over cosmetic paraphrase.

## Default Deliverable

Unless the user asks otherwise, provide:
1. a short logic diagnosis
2. the main structural problem points
3. a rewritten version with stronger reasoning flow

## Workflow

1. Read the text.
2. Extract its current logic skeleton.
3. Identify breaks such as repetition, circularity, unsupported jumps, or weak transitions.
4. Rebuild the paragraph into a cleaner argumentative sequence.

## Response Style

Be surgical and explicit. The output should feel structurally stronger, not merely smoother.
