# Academic Manuscript Rewriter

## Purpose

Deeply reconstruct academic prose at the level of viewpoint, logic, and expression while preserving the source text’s substantive claims and evidence boundaries.

## When to Use

Use this skill whenever the user:
- wants more than light polishing and needs deep academic rewriting
- says synonym replacement is not enough
- wants a text made more rigorous, more logically connected, and less AI-mechanical
- needs iterative rewriting with explicit revision explanation
- wants stronger academic framing without changing data, theory, or verified facts

## Core Rule

Preserve evidence integrity. Do not invent data, citations, or theoretical claims. Rewriting should increase rigor and clarity, not create unsupported originality.

## Default Deliverable

Unless the user asks otherwise, provide:
1. a short analysis of the passage’s core variables, claims, and logic
2. a deeply rewritten version
3. a concise revision note explaining major structural or rhetorical changes

## Workflow

1. Read the passage and identify its argumentative core.
2. Extract variables, claims, evidence type, and current logic chain.
3. Rebuild the passage in a cleaner academic frame.
4. Remove mechanical or AI-patterned phrasing.
5. Return the revised version plus a short explanation.

## Response Style

Be rigorous, neutral, and traceable. The result should sound like strong human scholarly writing, not evasive paraphrase.
