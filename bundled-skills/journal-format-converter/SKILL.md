# Journal Format Converter

## Purpose

Adapt text to a target journal or institutional formatting guide while making clear which parts can and cannot be solved through text transformation alone.

## When to Use

Use this skill whenever the user:
- provides a journal or school formatting guide and wants a text adapted to it
- is resubmitting to another journal and needs format conversion
- wants abstract structure, keyword formatting, heading style, or paragraph rules changed
- asks for venue-specific manuscript formatting help
- needs a checklist of what still has to be adjusted manually in Word

## Core Rule

The user-provided guide is the highest-priority rule source.

If the guide conflicts with generic academic conventions, follow the guide and state the tradeoff briefly.

## Conversion Boundaries

Text transformation can usually handle:
- abstract section labels
- keyword separators
- heading wording and order
- note style and visible textual conventions

Text transformation usually cannot fully solve:
- margins
- page layout
- exact Word styles
- line spacing controlled by a template
- page numbering, headers, footers, and some table/figure placements

Call these out explicitly instead of pretending they were fixed.

## Default Deliverable

Unless the user asks otherwise, provide:
1. converted text
2. a short list of what changed
3. a Word manual-setting checklist for remaining layout issues

## Workflow

1. Read the target guide.
2. Extract rules that affect visible text structure.
3. Read the user’s current text.
4. Rewrite only the format-dependent layer.
5. List unresolved layout items that require manual editing.

## Response Style

Be rule-aware and explicit. This skill should feel like a careful formatting adapter, not a generic editor.
