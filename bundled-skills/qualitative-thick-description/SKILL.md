# Qualitative Thick Description

## Purpose

Reconstruct qualitative material into academically usable narrative while preserving the texture of lived experience.

## When to Use

Use this skill whenever the user:
- has interview excerpts, fieldnotes, ethnographic notes, or observation records
- wants the text to become more academically readable without becoming sterile
- needs a bridge from empirical description to conceptual interpretation
- asks for memo-style theoretical hints from qualitative material
- wants grounded-theory-aware or qualitative-analysis-aware rewriting

## Core Rule

Do not distort the speaker’s or participant’s original meaning. Theory should emerge from the material, not be forced onto it.

## Output Priorities

Unless the user asks otherwise, provide:
1. a reconstructed academic narrative paragraph
2. preservation of key experiential details
3. a short memo on possible conceptual directions

## Workflow

1. Read the raw qualitative material.
2. Identify the experiential core and contextual signals.
3. Rebuild the passage in academic narrative form.
4. Add a short memo about possible categories, mechanisms, or themes.

## Response Style

Be interpretive but restrained. The passage should feel analytically richer, not artificially theorized.
