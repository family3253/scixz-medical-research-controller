# Reviewer Response Assistant

## Purpose

Turn reviewer feedback into a disciplined response strategy and professionally worded reply text.

## When to Use

Use this skill whenever the user:
- has reviewer or editor comments to answer
- needs a response letter or rebuttal structure
- wants help decomposing one reviewer paragraph into several actionable issues
- needs wording for agreement, partial agreement, or respectful disagreement
- wants page and line placeholders included in the response

## Core Rule

Every response should correspond to a real or intended revision action. Never claim that a revision was made if the evidence is not available.

## Default Deliverable

Unless the user asks otherwise, provide:
1. response stance per comment
2. a polished response paragraph or template
3. placeholders for page/line or figure/table evidence

## Workflow

1. Read the reviewer comment and the user’s draft response or intended action.
2. Split the comment into concrete issues.
3. Decide on stance: accept, partially accept, reasoned defense, or cannot implement.
4. Draft the response in professional journal style.
5. Preserve evidence placeholders when exact manuscript locations are not yet known.

## Response Style

Be respectful, precise, and non-defensive. The tone should be calm even when the review is sharp.
