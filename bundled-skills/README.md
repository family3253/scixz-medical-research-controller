# Bundled Skills

These are route-specific companion Skills distributed alongside SciXZ. Each subdirectory preserves the source package layout and can be installed independently.

Read the provenance and licensing notes in [`../BUNDLED_SKILLS.md`](../BUNDLED_SKILLS.md) before copying a component to another project. The top-level MIT license applies to the SciXZ controller and repository-authored documentation; it does not automatically relicense every bundled component.
