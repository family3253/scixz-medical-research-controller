# Nature Skills additive integration

SciXZ keeps the original workflow and adds the `Yuan1z0825/nature-skills` repository as an optional extension layer.

- Source: https://github.com/Yuan1z0825/nature-skills
- Pinned commit: `50851efc109c981be6cdc1ed5171a2eaa739d20a`
- Repository license: Apache-2.0.
- Integration mode: **additive**. Existing SciXZ primaries and contracts remain authoritative.
- Activation: user-requested Nature-style treatment or a narrowly justified supplemental capability.
- Handoff label: `optional_extension`.

## Preservation rules

1. Do not replace the existing primary Skill merely because a Nature Skill has a similar name.
2. Do not replace SciXZ's reviewer council, evidence gates, JANE/iPubMed requirements, or formal output contracts.
3. Use Nature Skills as a style pass, second opinion, claim/reference helper, figure pass, reader, or additional artifact.
4. If the user asks for a generic academic task, do not activate the whole Nature suite.
5. If a Nature Skill produces a supplemental artifact, label it separately and preserve the original deliverable.

## Optional extension map

| Existing route | Optional extension | Purpose |
|---|---|---|
| manuscript-writing | `nature-writing` | Nature-style drafting or argument refinement |
| language polishing | `nature-polishing` | Nature-style language/translation/compression pass |
| manuscript-review | `nature-reviewer` | Additional reviewer perspective, not council replacement |
| reviewer-response | `nature-response` | Supplemental rebuttal and cover-letter audit |
| literature/citations | `nature-academic-search`, `nature-citation`, `nature-ref-verifier` | Supplemental search, claim-source mapping, reference verification |
| figures/presentation | `nature-figure`, `nature-paper2ppt`, `nature-image2ppt` | Optional figure or slide production/refinement |
| paper understanding | `nature-reader`, `nature-paper-card` | Optional bilingual reader or evidence-chain card |
| reporting | `nature-statistics`, `nature-data` | Optional reporting and Data/Code Availability checks |

`nature-review-studio` remains separate and unchanged as the formal synchronized DOCX+Markdown review owner.
