# Design sources

This skill is an original implementation informed by these public patterns:

- https://github.com/LeeShuaiyu/codex-journal-submission-from-package-skill
- https://github.com/amine123max/JournalManuscript
- https://github.com/kchemorion/academic-manuscript-skill

The package does not copy upstream official-template bundles. Cached publisher profiles are deliberately not treated as current journal requirements; every named journal still needs an official-source check.
